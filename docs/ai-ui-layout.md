# 人机对弈美术界面

沿用打谱界面的运行时结构：世界空间棋盘与桌面背景，屏幕空间侧栏及棋盒棋盖，独立模态层。入口为正常人机对弈开局，无需额外场景。

- 棋盘使用现有木纹、程序网格和黑白棋子。棋盘向右靠拢，手数与坐标开关纵向放在棋盘和侧栏之间。
- 对局视角：棋盒、棋盖较最初同比例放大约 36%；电脑棋盒靠棋盘左上角，玩家棋盒靠右下角。棋盘保持原始大尺寸，不因棋盒放大而缩小；棋盒位置按窗口边缘适配，盒盖贴近各自棋盒，提子示意在盒盖内。棋盒颜色随玩家执棋切换。
- 侧栏复用胡桃木底板、宣纸记录卡和普通/认输按钮。新信息卡、青瓷按钮、独立圆框与两位水墨侧颜来自本次美术资源。
- 玩家/电脑固定左右两列；头像右下执棋标记、名称、提子数和计时分别对齐。贴目集中居中，剩余读秒次数置于用时右上方。
- 记录不显示表头，每手一行，格式为三位手数编号、黑/白棋子图案、落子坐标；支持让子后白棋先行、停一手及滚动。
- 第一行悔棋、停一手、和棋、认输；第二行形势判断、数目。不显示行棋状态文案和返回主界面按钮。
- 形势判断可点击开启/关闭：开启时以完整双方形势卡片替换右侧落子记录，显示黑白棋图案、目数、提子数及领先情况；关闭后恢复记录。卡片不阻挡行棋、不暂停计时，采用独立本地模拟估目器，计分与标记来自同一份后台结果；估计总分按活子与归属点计数，白方含贴目。详见 [算法说明](situation-estimator.md)。
- 认输与同排按钮共用宣纸底图和边框，用暗朱红文字区分。
- 复用现有棋局、AI、计时、数目、认输及棋谱保存逻辑。人机认输明确由玩家执棋方认输。

实现：`Assets/Scripts/GoGame.AiArt.cs`。新素材位于 `Assets/Resources/UI/AiMatch`，原始桌面与棋盒素材保留在 `Assets/Art/UI`。

验证：后台开发构建 `AiArtBuild.BuildPreview`；运行生成的 `Builds/AiUiPreview/GoGame.exe` 加 `-aiArtPreview` 参数，可检查布局、双方颜色与提子映射、读秒、记录、悔棋、开关、模态弹窗及页面恢复，并输出实际渲染截图。预览不连接外部 AI、不结束或保存真实棋局。

窗口检查：1600×900、1440×900、1280×720；棋盘检查：9、13、19 路。最终截图与验证报告保存在 `docs/ai-ui-preview`。
