# 打谱页面 UI 素材 v1

按已确认的暖木色、水墨书房风格制作，使用内置 image_gen 生成。素材位于 `Assets/Resources/UI/Kifu/`，均为独立透明背景 PNG，未烘焙文字、数字、图标。这些素材现已接入打谱页面，实际界面预览见 `docs/study-ui-preview/`。

| 文件 | 用途 |
| --- | --- |
| sidebar-walnut-v1.png | 右侧栏木纹底板 |
| record-parchment-v1.png | 行棋记录宣纸卡片 |
| button-parchment-v1.png | 通用操作按钮，叠加各自文字和图标 |
| judgment-dialog-v1.png | 形势判断弹窗底板 |
| toggle-walnut-v1.png | 手数、坐标深色切换按钮 |

当前接入布局：棋盘区域内居中，去除棋盘浅色遮罩；手数、坐标按钮上下排列，整体位于棋盘和右侧栏之间的垂直中心。右侧栏顶部黑左白右，其下双方数字中间显示“提子”；中间行棋记录；底部第一行悔棋、停一手、和棋、数目、认输，第二行形势判断、返回主界面。

形势判断弹窗：黑棋图案在左，白棋图案在右，中间动态显示“XXX领先XXX目”。两行数据分别为目数和提子数，标签放在双方数字中间。示例图中的数值仅为占位，实际接入需使用对局数据。

导入时保留透明通道；避免整图非等比拉伸导致边框变形。按钮与面板优先使用九宫格切片，实际切片边距需按图像边框和透明留白设置。文字和图标作为独立 UI 元素绘制。

完整生成提示词见 `kifu-ui-asset-prompts-v1.json`。
