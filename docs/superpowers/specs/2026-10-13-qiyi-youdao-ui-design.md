# 「棋弈有道」国风雅致 UI 设计规格

## 1. 文档状态

- 状态：设计已确认，待拆分实施计划
- 日期：2026-10-13
- 目标项目：GoGame
- 目标平台：Windows 桌面端
- 目标分辨率：1920×1080，兼容 1600×900 与 1366×768
- 方案：完整美术重制，2D 美术主导 + Unity UI 重构
- 品牌名：棋弈有道
- 英文副标：不使用
- 视觉方向：宋式清雅·夜案棋局

## 2. 设计目标

本设计为 GoGame 建立一套可以直接进入资源制作和 Unity 接入阶段的国风雅致 UI。目标不是增加传统装饰，而是让棋盘、棋谱、计时和 AI 分析都呈现安静、克制、清晰的东方气质。

核心关键词：

```text
宋式文人 / 乌木棋盘 / 宣纸留白 / 朱砂点睛 / 金石细线
静谧 / 克制 / 清晰 / 可读 / 可实现
```

产品体验设定为：夜色书斋中，一盏暖灯照着乌木棋盘，远处淡墨山水，近处是整理好的棋谱和小方印。

## 3. 已确认的产品和交互决策

### 3.1 主菜单

- 四个主按钮竖直排列：打谱、人机对弈、历史棋谱、退出；
- 设置按钮位于右上角；
- 音量快速控制位于右下角；
- 版本信息位于左下角；
- 产品标题使用“棋弈有道”，不使用英文副标。

### 3.2 人机设置

设置顺序：

```text
棋盘尺寸
执棋选择
贴目
让子
对局时间
读秒
电脑对手
```

对局时间选项：

```text
无限制 / 5分钟 / 1小时 / 2小时 / 自定义
```

读秒选项：

```text
无 / 3×30秒 / 5×30秒 / 5×60秒 / 自定义
```

自定义本时：1–600 分钟；自定义读秒次数：1–20 段；每段读秒：5–600 秒。

### 3.3 正式对局

棋盘左侧放置：

```text
手数 / 坐标 / 形势
```

右侧操作区一行放置：

```text
悔棋 / 停一手 / 数目 / 认输
```

正式对局底部只显示当前手数和行棋方，不显示上一手、下一手、回到终局。

### 3.4 打谱

打谱操作区同样包含：

```text
悔棋 / 停一手 / 数目 / 认输
```

打谱模式包含自动保存状态和棋谱信息卡，不显示 AI 专属状态，不显示复盘导航。

### 3.5 终局结果

认输时显示动态结果：

```text
黑方认输 → 白方中盘胜
白方认输 → 黑方中盘胜
```

数目结束后记录：

```text
黑方胜 X.X 目
白方胜 X.X 目
```

超时结束后记录败方原因：

```text
黑方超时 → 白方胜（黑方超时负）
白方超时 → 黑方胜（白方超时负）
```

## 4. 页面和状态架构

### 4.1 页面状态

```csharp
public enum GoUiPage
{
    Splash,
    MainMenu,
    AiSetup,
    Settings,
    Playing,
    Study,
    History,
    Review
}
```

导航关系：

```text
启动页
  ↓
主菜单
  ├── 打谱 → 打谱页面
  ├── 人机对弈 → 人机设置 → 正式对局
  ├── 历史棋谱 → 棋谱详情 → 复盘
  ├── 设置 → 通用设置
  └── 退出
```

### 4.2 Unity 层级

```text
GoAppRoot
├── SceneBackground
│   ├── InkBackground
│   ├── MountainSilhouette
│   └── SealDecoration
├── MainCanvas
│   ├── HeaderLayer
│   ├── ContentLayer
│   ├── BoardLayer
│   ├── SidePanelLayer
│   ├── BoardToolbarLayer
│   ├── BottomInfoLayer
│   └── OverlayLayer
├── ModalCanvas
│   ├── ConfirmDialog
│   ├── ScoreDialog
│   ├── SaveKifuDialog
│   ├── ResignDialog
│   ├── TimeoutDialog
│   └── ErrorDialog
└── TransitionLayer
```

层级职责：

- `SceneBackground` 只负责背景氛围；
- `MainCanvas` 负责页面、棋盘、侧栏和工具栏；
- `ModalCanvas` 负责阻断式弹窗；
- `TransitionLayer` 负责页面切换和加载；
- 棋盘输入和规则保持在现有业务层，不写入背景或纯视觉组件。

### 4.3 布局基准

1920×1080：

```text
安全区域：左右 120 px，上下 70 px
棋盘区：约 0–1280 px
侧栏区：约 1320–1870 px
侧栏宽度：480–540 px
底部信息栏：84–104 px
```

1366×768 降级规则：

- 侧栏压缩到 340–390 px；
- 分析图和次要说明可以折叠；
- 棋盘完整性优先；
- 正文不低于 13 px；
- 历史和分析侧栏允许垂直滚动。

## 5. 视觉设计系统

### 5.1 色板

| Token | 色值 | 用途 |
|---|---|---|
| `Ink900` | `#17130F` | 全局背景 |
| `Ink800` | `#211A14` | 侧栏、深色面板 |
| `Ink700` | `#2B2118` | 按钮、卡片 |
| `Wood900` | `#3A2413` | 棋盘外框 |
| `Wood700` | `#69431F` | 木纹和中层边框 |
| `Wood500` | `#A8753B` | 棋盘主体 |
| `Paper` | `#F2E8D1` | 主文字、宣纸卡片 |
| `PaperDim` | `#B9AA8C` | 次要文字 |
| `Gold` | `#D3A24C` | 选中、主按钮、星位 |
| `GoldSoft` | `#9D7838` | 分割线、弱高光 |
| `Cinnabar` | `#B64A3A` | 危险、恶手、错误 |
| `Jade` | `#6F9A82` | 成功、合法、就绪 |

面积比例：深色 60%，木/纸 25%，米白文字 8%，金色 5%，状态色 2%。

规则：金色不大面积铺满；颜色不能单独承担语义；朱砂只表达危险或错误；玉色表示稳定和成功。

### 5.2 字体

- `Display`：宋体或宋刻本风格，用于“棋弈有道”、页面标题和结果标题；
- `Body`：清晰黑体或现代宋体，用于按钮、设置、列表和说明；
- `Mono`：等宽或半等宽，用于手数、坐标、胜率、目差和计时；
- `BoardNumber`：清晰无衬线，用于棋盘数字和 PV 序号。

字号基准：

| 组件 | 字号 |
|---|---:|
| 产品标题 | 48–60 px |
| 页面标题 | 28–32 px |
| 区块标题 | 18–20 px |
| 正文 | 15–16 px |
| 按钮 | 16–18 px |
| 辅助文字 | 12–13 px |
| 棋盘手数 | 20–28 px |
| AI 数值 | 15–18 px |

### 5.3 材质和装饰

允许：低对比宣纸颗粒、轻微乌木纹、淡墨山水、细金线、小型朱砂印、极淡竹影。

禁止：高对比山水、大面积祥云、金色发光边框、复杂龙凤纹、过多花瓣、纹理覆盖正文。

## 6. 棋盘和棋子

### 6.1 棋盘

- 外框：`Wood900`；
- 主体：`Wood500` 的暖木色；
- 网格线：`#4F3218`，透明度 85%–92%；
- 星位：暗金或深棕；
- 木纹：低对比、透明度不超过 8%；
- 投影：右下偏移 8–12 px，透明度约 25%。

### 6.2 棋子

黑子使用 `#171717`、`#55504A` 高光和 `#050505` 暗部；白子使用 `#E8E0D0`、`#FFFDF6` 高光和 `#AFA58F` 暗部。棋子必须有独立阴影层。

### 6.3 标记

```text
最近一手：朱砂细环
AI 最佳点：金色外环
次选点：灰金外环
PV：金色序号
好手/推荐：玉色三角
疑问/风险：朱砂圆形或三角
```

### 6.4 棋盘侧边工具栏

靠近棋盘放置：

```text
[手数]
[坐标]
[形势]
```

手数开启时，黑子数字使用纸白，白子数字使用深棕；当前手使用朱砂环。数字随 9/13/19 路缩放。

## 7. 页面详细规格

### 7.1 启动页

中央显示“棋弈有道”和副句“一局清静，落子无声”。背景为淡墨山水。动画顺序为背景淡入、山水出现、Logo 淡入、朱砂印出现、主菜单淡入，总停留 1.2–2.0 秒。

### 7.2 主菜单

主按钮单列排列：

```text
打谱
人机对弈
历史棋谱
退出
```

按钮宽约 280 px，高约 64 px，间距 14–18 px。设置齿轮在右上角，音量滑杆在右下角，版本信息在左下角。悬停只提高边框亮度和出现短金线，不整体放大。

### 7.3 人机设置页

中央宣纸卡片，选项顺序为棋盘尺寸、执棋选择、贴目、让子、对局时间、读秒、电脑对手。

AI 对手卡片显示：

```text
本地引擎：离线可用，速度较快，棋力有限
KataGo：高强度分析，需要本机引擎和模型
大模型：联网选点，需要 API 密钥
```

时间控制：

```text
对局时间：无限制 / 5分钟 / 1小时 / 2小时 / 自定义
读秒：无 / 3×30秒 / 5×30秒 / 5×60秒 / 自定义
```

### 7.4 通用设置页

左侧目录、右侧内容：

```text
音量 / 界面 / 棋盘 / AI引擎 / 快捷键 / 关于
```

包含主音量、音乐、音效、手数、坐标、形势、减少动效、KataGo 路径/模型/配置、benchmark 和快捷键。

### 7.5 正式对局

布局为大棋盘 + 双方信息卡 + 落子记录 + AI 状态 + 操作区。棋盘左侧是手数/坐标/形势工具栏；右侧底部操作一行排列：

```text
悔棋 / 停一手 / 数目 / 认输
```

底部只显示当前手数和行棋方。正式对局不显示上一手、下一手和回到终局。

双方信息卡显示昵称、段位、剩余时间、时间模式和当前行棋状态。计时显示支持无限制、本时和读秒。

### 7.6 打谱

打谱使用更安静的右侧棋谱信息卡和自动保存状态。操作区为：

```text
悔棋 / 停一手 / 数目 / 认输
```

打谱支持认输，确认后记录动态的“黑方中盘胜”或“白方中盘胜”。打谱不显示 AI 状态和复盘专用导航。

### 7.7 历史棋谱

使用棋谱卡片列表，支持搜索、筛选、排序、详情、打开复盘、导出 SGF、编辑信息和删除保护。结果显示统一使用：

```text
黑方胜 X.X 目
白方胜 X.X 目
黑方中盘胜
白方中盘胜
白方胜（黑方超时负）
黑方胜（白方超时负）
```

### 7.8 复盘与 AI 分析

棋盘左侧，右侧依次放当前局面、候选点、胜率/目差图、批注和恢复实战。底部使用复盘时间轴。

复盘页面才显示：

```text
上一手 / 下一手 / 回到终局
```

全局分析、AI 推演和恢复实战是顶部状态入口。PV 默认最多 15 手，用户确认后才能转为正式分支。

## 8. 动效和音频

### 8.1 动效

| 动效 | 时长 |
|---|---:|
| 页面切换 | 220 ms |
| 面板展开 | 180 ms |
| 按钮悬停 | 120 ms |
| 按钮点击 | 80 ms |
| 落子 | 100 ms |
| 分析结果出现 | 260 ms |
| AI 思考脉冲 | 900 ms 循环 |

不使用棋子弹跳、旋转、强发光或全屏闪烁。提供“减少动效”设置。

### 8.2 音频

资源：

```text
button_click.wav
button_confirm.wav
stone_place.wav
stone_capture.wav
clock_warning.wav
game_end.wav
bgm_study.ogg
bgm_review.ogg
```

默认值：主音量 70%，音乐 25%，音效 65%，计时提醒 80%。音量控件在主菜单右下角，完整设置在设置页。

## 12. 设计边界

本设计暂不包含：

- 在线对弈；
- 用户账号；
- 商店和付费资源；
- 移动端竖屏布局；
- 复杂 3D 书房场景；
- 大量动态粒子和实时天气；
- 新的 AI 算法实现。

这些功能如未来需要，应单独建立设计和实施计划，不与本次 UI 重制混合。
